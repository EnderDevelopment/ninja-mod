# Ninja Mod

Enhance your Minecraft experience with a custom HUD, Kekkei Genkai system, and Jutsu items.

## Features

- Custom HUD with Chakra bar (100 max, 2/s regen) and Ninja XP counter
- Kekkei Genkai system (300 XP trigger)
- Jutsu items (Kamui Eye, Eighth Gate, Chidori)
- Ten-Tails Husk boss

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/ninja-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with Fabric Loader.

## Usage

### Commands

| Command | Description |
|---------|-------------|
| `/addninjaxp <amount>` | Adds Ninja XP to the player |
| `/executejutsu <jutsu>` | Executes a Jutsu (kamuieye, eighthgate, chidori) |

### Permissions

No specific permissions are required for this mod.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
